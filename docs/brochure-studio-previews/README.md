# Brochure Studio — nine design/format previews

Browser captures from the detached-home test fixture. These are layout examples,
not a representation of the pictured property or a live listing. Photography
comes from the existing demonstration assets. The full matrix also tests long
condo addresses, a loft, portrait photos, missing floor plans and brand variants.

Folded images show the outside spread: back cover left, front cover right.
The Preview lets you inspect the inside spread and every Letter page.
